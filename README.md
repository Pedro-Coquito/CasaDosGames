## Como Executar a Aplicação

Siga o passo a passo abaixo para clonar e rodar o projeto localmente em seu ambiente de desenvolvimento.

# 1. Clonar o repositório

Abra o seu terminal e execute o comando abaixo para clonar o projeto:

```
git clone https://github.com/matheus-soares-simao/CasaDosGames.git
```

# 2. Acessar a pasta do projeto

Navegue até o diretório recém-criado:

```
cd CasaDosGames
```

# 3. Instalar as dependências

Instale todas as dependências necessárias listadas no projeto:
```
# Usando npm
npm install

# Ou se preferir usar yarn
yarn install
```
